## 🐛 **TROUBLESHOOTING**

### Messages not appearing?
```
→ Refresh page (Ctrl+R)
→ Check browser console (F12)
→ Clear cache (Ctrl+Shift+Delete)
```

### Send button not working?
```
→ Check if message field has text
→ Try keyboard shortcut (Ctrl+Enter)
→ Refresh the page
```

### Chats not saving?
```
→ Check localStorage is enabled
→ Try in different browser
→ Check console for errors (F12)
```

### Models not switching?
```
→ Click dropdown [🤖 Advanced AI ▼]
→ Select different model
→ Send new message
→ Response should be different
```

## 🎯 **COMMON TASKS**

### Create Multiple Chats
```
1. Click [✨ New Chat]
2. Send message
3. Click [✨ New Chat] again
4. Send different message
5. Click old chat to switch
```

### Switch Between Models
```
1. Click [🤖 Advanced AI ▼]
2. Select model
3. Send message
4. Notice different response style
```

### Copy Code Block
```
1. Get response with code
2. Hover over code block
3. Click [📋 Copy]
4. Wait for [✓ Copied!]
5. Paste anywhere
```

### Change Theme
```
1. Click [🌙] or [☀️]
2. Theme switches instantly
3. Setting auto-saves
4. Persists on refresh
```
