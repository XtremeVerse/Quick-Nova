### 🎯 **How to Use**

#### Sending a Message
1. Type in the input field at the bottom
2. Click the **Send button** (➤) OR press **Ctrl+Enter**
3. Wait for AI response
4. See typing indicator while processing

#### Switching Models
1. Click the **model dropdown** in header (🤖 Advanced AI ▼)
2. Select any of 6 models:
   - 🤖 Advanced AI
   - 🚀 ChatGPT-4 Style
   - ✨ Gemini Pro
   - 🧠 Claude 3
   - ⚡ Fast Response
   - 🎨 Creative Mode
3. Start chatting - responses match the selected model's style!

#### Creating New Conversations
1. Click **✨ New Chat** button in sidebar
2. Start typing and send message
3. Chat is automatically added to history
4. Previous chats stay in sidebar for later reference

#### Managing Chat History
- Click any chat in the sidebar to load it
- All messages are preserved
- Chat title auto-updates from first message
- Auto-saving to localStorage

#### Theme Toggle
1. Click the **moon/sun icon** (🌙) in top right
2. Theme switches between Dark ↔ Light mode
3. Preference saved automatically

#### On Mobile
1. Tap the **☰ menu button** to open sidebar
2. Tap anywhere on overlay to close sidebar
3. All buttons are properly sized for touch
4. Full responsive experience
