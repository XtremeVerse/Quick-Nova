# QuickNova - Modern Productivity Tools Suite

QuickNova is a comprehensive collection of 30+ free online productivity tools, featuring a modern, glassmorphism-inspired UI with neon accents and dark/light mode support.

## 🚀 Features

- **Modern UI/UX:** Glassmorphism design, neon glow effects, smooth animations.
- **Responsive:** Mobile-first design that works perfectly on all devices.
- **Dark/Light Mode:** Automatic system detection with manual toggle.
- **Client-Side Privacy:** Most tools run entirely in the browser (no server upload required).
- **Free Built-in AI:** Powerful AI tools (Chat, Image, Text) included for free - no API keys required!

## 🛠️ Included Tools

### AI Tools (Free & Unlimited)
- **AI Chat:** Intelligent chat assistant (GPT-4 class).
- **AI Image Generator:** Create stunning images from text prompts.
- **Text Summarizer:** Summarize long articles instantly.
- **Story Generator:** Create creative stories from simple ideas.
- **Text Rewriter:** Rewrite text in different tones (Professional, Funny, etc.).

### Image Tools
- **Background Remover:** Remove image backgrounds automatically (Client-side AI).
- **Image Resizer:** Resize images by dimension or percentage.
- **Image Compressor:** Compress JPG/PNG/WEBP images locally.
- **Image to PDF:** Convert images to PDF documents.
- **Meme Generator:** Create custom memes with text.

### Utility Tools
- **Unit Converter:** Convert Length, Weight, Temperature, Data, Time.
- **Color Picker:** Hex, RGB, HSL converter with palette generator.
- **Word & Character Counter:** detailed text statistics with social media limits.
- **QR Code Generator:** Create customizable QR codes.
- **Password Generator:** Secure random password creator.
- **JSON Formatter:** Validate and beautify JSON data.

### Media & Document Tools
- **PDF Tools (New!):**
  - **Image to PDF:** Convert multiple images to a single PDF.
  - **PDF Merge:** Combine multiple PDFs into one.
  - **PDF Split:** Extract pages or split PDF into separate files.
  - **Word to PDF:** Convert DOCX files to PDF.
  - **PDF to Word:** Extract text from PDF to DOCX.
  - **PDF Compressor:** Optimize and reduce PDF file structure.
  - **Text to PDF:** Convert plain text to PDF documents.
- **Voice Recorder:** Record and download audio (Web Audio API).
- **Audio to Text:** Real-time speech transcription (Web Speech API).
- **Video to MP3:** Extract audio from video files (Client-side FFmpeg).
- **MP3 Cutter:** Trim and cut audio files (Waveform visualizer).

### Technical Stack

- **HTML5:** Semantic structure.
- **CSS3:** Custom properties (variables), Flexbox/Grid, Glassmorphism.
- **JavaScript (ES6+):** Modular logic, Async/Await for APIs.
- **Libraries (via CDN):**
  - `jspdf` & `html2pdf` (PDF generation)
  - `pdf-lib` (PDF manipulation)
  - `mammoth.js` (Word to HTML)
  - `docx` (Word generation)
  - `pdf.js` (PDF reading)
  - `jszip` (File archiving)
  - `qrcode.js` (QR Code generation)

## 📦 Installation & Deployment

1. **Local Development:**
   - Clone the repository.
   - Open `index.html` in your browser.
   - Or use a local server: `npx serve .`

2. **Deployment:**
   - Ready for Netlify, Vercel, or GitHub Pages.
   - Simply upload the root directory.

## 🔑 API Configuration

No API configuration is required! The site uses public inference APIs (like Pollinations.ai) to provide free AI features out of the box.
