## 🚀 **How to Use**

### Basic Workflow
```
1. Visit: http://localhost:8080/tools/ai-chat.html
2. Type message in input field
3. Click Send button (➤) or press Ctrl+Enter
4. See typing indicator (⏳)
5. Get AI response in model's unique style
6. Repeat!
```

### Switch Models
```
1. Click header dropdown: [🤖 Advanced AI ▼]
2. Select different model
3. Ask same question
4. Get different response style!
```

### Manage Chats
```
1. New Chat: Click [✨ New Chat] in sidebar
2. Load Chat: Click any chat in sidebar history
3. Delete: Clear all chats with browser data
```

### Toggle Theme
```
1. Click icon in top right: [🌙] or [☀️]
2. Theme switches instantly
3. Preference saved automatically
```
